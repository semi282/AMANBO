# 📥 찬성 RAW 데이터 보관소 (Raw Data Vault)

> **용도**: 기사 원문, 논문 PDF 발췌본, 인터뷰 전문, 커뮤니티 반응 등 **가공되지 않은 날것의 원본 데이터**를 보관합니다.

---

## 🏷️ 파일 명명 규칙
* `[김민주-자료제목_원문].md` (또는 원본 파일)
* 예시: `[김민주-2024_GDC_인디게임_AI도입사례_기사].md`

---

## 🔄 처리 파이프라인
1. 이 폴더에 원문 텍스트를 저장합니다.
2. `[[찬성/schema/prompt_pipeline|찬성 변환 프롬프트]]`를 사용하여 LLM(ChatGPT, Claude)에 원문을 입력합니다.
3. LLM이 생성한 정제 문서를 `[[찬성/wiki/]]` 폴더에 저장합니다.
4. `[[찬성/README|찬성 리드미]]` 활동 로그에 `YYMMDD HH:mm` 형식으로 기록합니다.
