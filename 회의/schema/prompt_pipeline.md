# 🤖 [회의] 회의 메모(RAW) → 종합 회의록(WIKI) 변환 프롬프트

> 회의 중 작성한 거친 메모나 녹취록을 LLM에게 주어 규격화된 종합 회의록 문서로 자동 변환시키는 프롬프트입니다.

---

## 📋 변환 프롬프트 복사하기

```markdown
당신은 아만보팀의 회의 서기 AI입니다.
아래에 제공되는 [회의 메모 RAW 데이터]를 읽고, 우리 팀의 [회의록 스키마]에 맞추어 완벽한 마크다운 종합 회의록으로 정리해주세요.

### [준수 규칙]
1. 제목 형식은 "[yy.mm.dd]-주제"로 작성하세요. (예: [26.09.16]-게임_AI_활용_바운더리_회의록)
2. 참석자 3명(함석신 1993, 김민주 1994, 김준호 1999)의 찬성/중립/반대 하브루타 대립각을 명확히 살려 정리하세요.
3. 합의된 사항(Consensus)과 여전히 팽팽한 이견을 분리하여 기록하세요.
4. 마지막 섹션에는 담당자별 다음 액션 아이템(Action Items) 표를 반드시 포함하세요.
5. 옵시디언 위키링크 [[문서명]] 문법을 활용하세요.

---
### [회의 메모 RAW 데이터]
(여기에 회의 녹취록, 메모, 브레인스토밍 낙서 등을 붙여넣으세요)
```
