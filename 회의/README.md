## 🔄 회의 LLM WIKI 아키텍처

```mermaid
flowchart LR
    A["📥 raw/<br>(회의 녹취/메모)"] --> B["📐 schema/<br>(회의록 스키마)"]
    B --> C["🧠 wiki/<br>(종합 회의록)"]
    C --> D["📊 README.md<br>(회의 히스토리 로그)"]
```

### 1. 📂 폴더별 역할
* **`📂 raw/`**: 회의 녹취록, 브레인스토밍 메모, 개별 안건 원본 요약
* **`📂 schema/`**: 종합 회의록 Frontmatter 규격 및 인제스트 프롬프트
* **`📂 wiki/`**: 논점 분석, 합의 사항, Action Items가 정제된 공식 종합 회의록
