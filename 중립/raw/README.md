# 📥 중립 RAW 데이터 보관소 (Raw Data Vault)

> **용도**: 각국 정부 규제안, 스팀/에픽 약관, 저작권위원회 연구 보고서, 뇌과학 논문 등 **가공되지 않은 원본 데이터**를 보관합니다.

---

## 🏷️ 파일 명명 규칙
* `[함석신-자료제목_원문].md` (또는 원본 파일)
* 예시: `[함석신-밸브_스팀_AI콘텐츠_출시정책_공식문서].md`

---

## 🔄 처리 파이프라인
1. 이 폴더에 원문 텍스트를 저장합니다.
2. `[[중립/schema/prompt_pipeline|중립 변환 프롬프트]]`를 사용하여 LLM에 원문을 입력합니다.
3. LLM이 생성한 정제 문서를 `[[중립/wiki/]]` 폴더에 저장합니다.
4. `[[중립/README|중립 리드미]]` 활동 로그에 `YYMMDD HH:mm` 형식으로 기록합니다.
