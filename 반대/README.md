## 🔄 반대 LLM WIKI 아키텍처

```mermaid
flowchart LR
    A["📥 raw/<br>(소송문/성명서 원본)"] --> B["📐 schema/<br>(리스크 분석 파이프라인)"]
    B --> C["🧠 wiki/<br>(정제된 비판 위키 지식)"]
    C --> D["📊 README.md<br>(활동 로그 & 색인)"]
```

### 1. 📂 폴더별 역할
* **`📂 raw/`**: 소송 판결문, 노조 성명서, 불매 운동 보도 등 가공 전 원시 자료
* **`📂 schema/`**: 리스크 요인 및 판례를 객관적으로 추출하는 스키마 명세서 및 LLM 변환 프롬프트
* **`📂 wiki/`**: 저작권 리스크 분석과 하브루타 공격 논리가 정제된 위키 문서
