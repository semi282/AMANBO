# 📥 반대 RAW 데이터 보관소 (Raw Data Vault)

> **용도**: 저작권 소송 판결문, 노조/협회 성명서, 불매 운동 사례 기사, 커뮤니티 고발 글 등 **가공되지 않은 원본 데이터**를 보관합니다.

---

## 🏷️ 파일 명명 규칙
* `[김준호-자료제목_원문].md` (또는 원본 파일)
* 예시: `[김준호-할리우드_성우_게임AI파업_합의문_전문].md`

---

## 🔄 처리 파이프라인
1. 이 폴더에 원문 텍스트를 저장합니다.
2. `[[반대/schema/prompt_pipeline|반대 변환 프롬프트]]`를 사용하여 LLM에 원문을 입력합니다.
3. LLM이 생성한 정제 문서를 `[[반대/wiki/]]` 폴더에 저장합니다.
4. `[[반대/README|반대 리드미]]` 활동 로그에 `YYMMDD HH:mm` 형식으로 기록합니다.
