# 📥 함석신 RAW 데이터 보관소 (Raw Data Vault)

> **연구자**: 함석신  
> **팀 주제**: 게임 제작을 위한 AI 활용은 어디까지 인정될 수 있을까?  
> **용도**: 플랫폼(스팀 등) 약관, AI 저작권 가이드라인, 창작물 유사도 분석 기술 자료, AI와의 대화 등 **가공되지 않은 날것의 원본 데이터**를 보관합니다.

---

## 🏷️ 파일 명명 규칙
* `[함석신-자료제목_원문].md` (또는 원본 파일)
* 예시: `[함석신-스팀_AI콘텐츠_라벨링_정책_원문].md`

---

## 🔄 처리 파이프라인
1. 이 폴더에 원문 텍스트나 AI 대화 내용을 저장합니다.
2. `[함석신 변환 프롬프트](../schema/prompt_pipeline.md)`를 사용하여 LLM에 원문을 입력합니다.
3. LLM이 생성한 정제 문서를 `../wiki/` 폴더에 저장합니다.
4. `[함석신 리드미](../README.md)` 활동 로그에 `YYMMDD HH:mm` 형식으로 기록합니다.
