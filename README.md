### 2. 🏷️ 파일 명명 & 로그 작성 규칙 (Naming & Log Rules)

#### ① 개별 자료 업로드 (`찬성`, `반대`, `중립` 폴더)
* **파일명 규칙**: `[작성자-제목].md`
* **예시**:
  * `찬성/[김민주-인디게임_AI활용_효율화사례].md`
  * `반대/[김준호-AI생성물_저작권소송_및_불매사례].md`
  * `중립/[함석신-스팀_AI_라벨링_의무화_분석].md`

#### ② 회의록 저장 (`회의` 폴더)
* **파일명 규칙**: `[yy.mm.dd]-주제.md`
* **예시**: `회의/[26.09.16]-게임_AI_활용_바운더리와_인지_외주화_종합_회의록.md`

#### ③ ⏱️ 각자 리드미 로그 타임스탬프 규칙 (`YYMMDD HH:mm`)
* 각 폴더(`찬성`, `반대`, `중립`, `회의`)의 `README.md`에 새로운 자료를 올리거나 수정할 때마다 **`YYMMDD HH:mm`** 형식으로 활동 로그를 작성합니다.
* 예시:
  ```markdown
  | 타임스탬프 (`YYMMDD HH:mm`) | 작업자 | 작업 내용 및 링크 | 비고 |
  | :---: | :---: | :--- | :--- |
  | `260916 17:48` | 김민주 | [김민주-AI생산성_혁신].md 추가 | 신규 등록 |
  ```

### 3. 🤖 LLM 연계 방법 (Obsidian + AI)
* **Obsidian 위키링크 지원**: 모든 문서는 `[[문서명]]` 형식으로 상호 연결되어 지식 그래프를 형성합니다.
* **표준 Frontmatter 메타데이터**:
  ```yaml
  ---
  title: "[작성자-제목]"
  author: "작성자명"
  created: "260916 17:48"
  updated: "260916 17:48"
  category: "찬성 | 반대 | 중립 | 회의"
  tags: [AI_토론, LLM_WIKI]
  summary: "핵심 요약 한 문장"
  ---
  ```
* 새 문서를 작성할 때는 `[[_templates/llm_wiki_template.md]]`를 복사하여 사용하세요.
