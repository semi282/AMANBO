## 📁 디렉토리 구조 및 아카이빙 룰

프로젝트 내 모든 자료는 아래 폴더 분류와 명명 규칙을 반드시 준수합니다.

```
AMANBO/
├── 📂 찬성/       # AI 찬성 입장 관련 자료, 긍정적 논거 및 연구 리포트
├── 📂 반대/       # AI 반대 입장 관련 자료, 위험성/저작권 리스크 및 사례
├── 📂 중립/       # 규제, 법제, 플랫폼 가이드라인, 절충안 및 통계 데이터
└── 📂 회의/       # 일자별 종합 회의록 및 프로젝트 기획서 아카이브
```

### 🏷️ 파일 명명 규칙 (Naming Rules)

1. **개별 자료 업로드 시 (찬성 / 반대 / 중립 폴더)**
   * **규칙**: `[작성자-제목].md`
   * **예시**:
     * `찬성/[김민주-게임AI_도입과_개발생산성_혁신].md`
     * `반대/[김준호-원화가_저작권_침해_및_일자리_위협].md`
     * `중립/[함석신-스팀_AI_라벨링_의무화_분석].md`

2. **회의록 아카이브 시 (회의 폴더)**
   * **규칙**: `[yy.mm.dd]-주제.md`
   * **예시**:
     * `회의/[26.09.16]-게임_AI_활용_바운더리와_인지_외주화_종합_회의록.md`
